# Megha & Saksham Wedding Invitation
Mobile-first static website with a vertical event itinerary and 7 dedicated event invitation pages.

## Files
- `index.html`: main invitation and vertical itinerary
- `maata-poojan.html`
- `mehendi-ceremony.html`
- `sangeet.html`
- `haldi-ceremony.html`
- `ring-ceremony.html`
- `phere.html`
- `blessing-reception.html`
- `styles.css`, `script.js`, `assets/`

## Preview locally
Open `index.html`, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Add music and photos
Add your licensed music file at `assets/music.mp3`.
Replace the three gallery placeholders in `index.html` with your own photo `<img>` tags and put the files under `assets/`.

## Deploy to Vercel
Import the GitHub repository into Vercel. Choose Framework Preset `Other`, leave Build Command blank, and set Output Directory to `.` (root).
